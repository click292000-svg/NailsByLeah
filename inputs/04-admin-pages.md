# 4. Administrator Pages

Tools for managing appointments, services, schedules, reports, and activity.

| No. | Ref | Requirement |
|---|---|---|
| 4.1 | 11.1 | Dashboard showing today's bookings, pending bookings, and total collected booking deposits. |
| 4.2 | 11.2 | Booking management actions: **Confirm, Reschedule, Complete, Cancel**. |
| 4.3 | 3.1 | When cancelling a booking, the administrator must select a reason from a dropdown: Staff unavailable, Schedule conflict, Emergency, Client did not respond, and Others. |
| 4.4 | 3.2 | Provide an optional explanation field for the cancellation. It must not be mandatory. |
| 4.5 | 11.5 | Booking search and filtering by booking date, booking status, or client name. |
| 4.6 | 11.3 | Service management page to update service prices and add-ons without changing source code. |
| 4.7 | 11.4 | Calendar/slot view to block specific dates or time slots for days off, holidays, or other unavailability. |
| 4.8 | 11.6 | Daily and monthly sales report pages. |
| 4.9 | 11.7 | Activity log page listing the user, the action performed, and its date and time. |
